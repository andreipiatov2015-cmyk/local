# Данные сервера — Android-приложение

Приложение подключается к серверу по **IP и порту** и показывает его данные:
список с поиском, карточка записи со всеми полями, автообновление каждые 30 секунд
(пока приложение открыто) и кнопка «Обновить».

```
ServerData/
├── app/                 ← Android-приложение (Kotlin, Jetpack Compose)
├── server/              ← пример сервера на Python (server.py + data.json)
├── SERVER_API.md        ← что реализовать на сервере + настройка удалённого доступа
└── README.md
```

## 1. Проверить на тестовом сервере

На компьютере с Python 3:

```
cd server
python3 server.py
```

Узнайте IP компьютера (`ipconfig` в Windows, `ip a` в Linux) и в приложении
введите его и порт `8000`. Телефон должен быть в той же Wi-Fi сети.
Поменяйте `data.json` — через ≤30 секунд изменения появятся на телефоне.

## 2. Собрать APK

1. Установите [Android Studio](https://developer.android.com/studio) (бесплатно).
2. **File → Open** → выберите папку `ServerData`. Дождитесь окончания синхронизации Gradle
   (первый раз скачивает компоненты, 5–15 минут). Если Studio предложит обновить
   Gradle/AGP — можно соглашаться.
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk` — его можно
   отправить пользователям (в Telegram, по почте) и установить, разрешив
   «установку из неизвестных источников».

Или подключите телефон по USB с включённой отладкой и нажмите ▶ Run.

## 3. Подключить свою программу

Смотрите `SERVER_API.md`: на сервере нужно добавить два адреса —
`GET /api/info` и `GET /api/items` — которые отдают JSON. Состав полей
задаёт сервер, приложение покажет любые поля без переделки.

## Что где в коде

| Файл | Что делает |
|------|-----------|
| `data/Api.kt` | Запросы к серверу и разбор JSON, понятные тексты ошибок |
| `data/Settings.kt` | Последний IP/порт и список недавних подключений |
| `MainViewModel.kt` | Подключение, синхронизация, автообновление |
| `ui/Screens.kt` | Экраны: подключение, список, карточка записи |

Интервал автообновления — `intervalSec` в `Settings.kt` (по умолчанию 30 с).
